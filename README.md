# SalonPro Manager (PHP + SQL + PWA)

نظام إدارة صالون نسائي احترافي ومتجاوب (موبايل/تابلت/دسكتوب) مع دعم التثبيت كتطبيق ويب (PWA).

## المزايا المنفذة
- واجهة RTL احترافية مع Sidebar قابل للإخفاء والإظهار.
- وحدات: الزبائن، الحجوزات، الزيارات، الخدمات، المخزن، المناسبات، الموظفات، المتابعة، مواعيد اليوم، التقارير، مستخدمي النظام.
- تقويم حجوزات متجاوب.
- نافذة منبثقة للإضافة السريعة.
- طباعة فاتورة حرارية.
- Service Worker + Manifest لدعم PWA.
- مخطط SQL متكامل مع Views للتقارير.

## التشغيل
```bash
php -S 0.0.0.0:8080 -t public
```
ثم افتح:
`http://localhost:8080/index.php`

## قاعدة البيانات
- عدّل إعدادات الاتصال في: `config/database.php`
- نفذ مخطط الجداول:
```bash
mysql -u root -p salonpro < database/schema.sql
```

## ملاحظات التوسعة
- تم تجهيز بنية قابلة للربط CRUD لكل وحدة.
- يمكن إضافة نظام صلاحيات مفصل لكل مستخدم عبر role-based middleware.
